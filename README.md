# Penfield Releases

Published installers for Penfield software. **No source code lives here** —
this repository is distribution-only.

## Penfield Fusion

Local-first neuroimaging workspace — ingest, register, and segment
whole-brain MRI on your own machine. Data never leaves your computer.

- **Licence required** — subscribe at https://penfield-tau.vercel.app/products/fusion
- Downloads are on the [Releases](../../releases) page
- Quick start: install → launch → paste your licence key → demo brain loads

Builds are currently **unsigned** (certificates cost money the project
doesn't have yet): macOS right-click → Open; Windows SmartScreen →
More info → Run anyway. Every build is produced by CI, not a laptop.

Research software — not for clinical diagnosis.
